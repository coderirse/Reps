# Reps 产品文档

> Slogan: **One more rep.**
> 版本: v0.1（MVP 规划稿） · 日期: 2026-08-30
> 配套文档: [开发文档](./DEVELOPMENT.md)

---

## 1. 产品定位

把老师下发的 CSV 题库，一键变成手机上可反复背诵的交互式刷题应用。告别打印、手写遮盖答案、翻页找解析的痛苦。

- **完全本地离线**：无网络请求、无账号、无云服务、无广告、无统计 SDK
- **开源免费**：MIT 协议，无内购、无订阅
- **极简专注**：只做「刷题 + 背题」一件事，拒绝社交、排行榜、社区

## 2. 背景与痛点

| 现状痛点 | Reps 的解法 |
|---|---|
| 老师发 PDF/Word 题库，学生打印或复印，费用高、不便携 | 一次 CSV 导入，手机随身刷 |
| 用纸笔遮盖答案背题，效率低、易误看 | 背题模式 A（答案直接展开）/ B（选后判分）一键切换 |
| 错题靠手抄错题本 | 自动归集错题，做对 2 次自动「掌握」移出 |
| 现有刷题 App 普遍要登录、看广告、氪金解锁题库 | 无账号无广告，题库永远是用户自己的 |
| 刷题进度怕丢 | 切题即存 + 定时静默存 + 生命周期兜底存 |

## 3. 目标用户与场景

**Persona：备考的大学生**（考研政治/专业课、期末、证书考试）。拿到老师/学长整理的题库（Excel 转的 CSV），考前 1–4 周反复刷。

三个核心场景：

1. **第一次导入**：选 CSV → 预览前 50 题确认格式没问题 → 命名「马原期中题库」→ 入库。
2. **日常刷题（模式 B）**：顺序/随机/章节专项刷，即时判分，错题自动进错题本，中途退出下次无缝续刷。
3. **考前冲刺（模式 A）**：只看答案和解析快速过一遍题库，重点题收藏，错题本里只刷没掌握的。

## 4. 竞品与同类项目调研

对 GitHub 上的开源同类项目做了一轮调研（2026-08）：

| 项目 | 形态 | 值得借鉴 | 与 Reps 的差异 |
|---|---|---|---|
| [LearnHelper](https://github.com/qyn1126/LearnHelper)（Android/Kotlin） | 原生刷题 App：多题库管理、智能刷题、错题自动收录、Markdown 渲染、刷题分析 | **随机模式持久化种子**（关 App 也不丢题序）、错题自动收录、刷题页直接编辑 | 含 AI 答疑（需联网），与离线约束冲突；Reps 砍掉分析/AI，专注背题闭环 |
| [EXAM-MASTER](https://github.com/CiE-XinYuChen/EXAM-MASTER)（Flask + Android） | 在线刷题系统，CSV 导入题库、顺序/随机/定时/模拟考、收藏/标记/错题 | CSV 数据格式的字段设计、模拟考概念 | 依赖服务端，非纯本地；Reps 全部离线 |
| [problem-killer](https://github.com/serfend/problem-killer)（Web/Vue） | 浏览器本地题库刷题，无需服务器 | **极速模式**（做对的题直接过）、**斩杀模式**（掌握后隐藏）、连对筛选 | 非原生移动端，交互密度为桌面设计 |
| [MiaowTest 题喵喵](https://github.com/qijun1900/MiaowTest) | 跨平台 AI 刷题 | 题型覆盖（选择/判断/填空/简答）、笔记本与复习链路 | AI 依赖云；Reps 的笔记功能可借鉴其「错题+笔记」联动 |
| [AnkiDroid](https://docs.ankidroid.org/)（Android/Java+Kotlin） | 记忆卡片，SM-2 间隔重复 | 间隔重复调度的思路（远期）；**导入设计教训：避免「整库替换」式导入** | 学习模型过重，对「题库刷题」场景是杀鸡用牛刀 |
| 错题本类 App（[知乎测评](https://zhuanlan.zhihu.com/p/141765345)） | 录题→复习→批改闭环 | 「错题列表 → 选题组卷」交互 | 多为闭源 + 付费 |

**调研结论**：市面上没有一款同时满足「**完全离线 + CSV 导入 + 背题模式 A/B 切换 + 错题/收藏闭环 + 原生 Compose + MIT 开源**」的应用。现有项目要么联网（AI/云题库）、要么 Web 端、要么学习模型过重。Reps 的差异化就锚定在这四点的交集上。

## 5. 产品原则

1. **离线是硬约束**：manifest 不声明 INTERNET 权限，从根上杜绝数据外传（这是可验证的隐私承诺）。
2. **状态不可丢失**：用户进度 > 一切；崩溃、强杀、换机（本地备份）都要能恢复。
3. **背题优先于考试**：本工具的核心是「背诵记忆」，判分只是手段，所以提供不做题只看答案的模式 A，且切换不丢状态。
4. **每一步可撤销/可确认**：删除题库、清除数据必须二次确认；导入前必须预览。

## 7. 功能需求

优先级标注：**P0** = MVP 必须；**P1** = MVP 内尽力；**P2** = 未来版本。

### 7.1 题库管理（P0）

| # | 需求 | 验收标准 |
|---|---|---|
| A1 | 从本地文件选择 CSV（系统文件选择器） | 支持 `.csv`/`.txt`；选中后立即可预览 |
| A2 | 解析并预览前 50 题 | 显示题号/题型/题干/正确答案；同时报告：总行数、解析失败行数及原因（行号+原因）、被跳过的不支持题型数量 |
| A3 | 自定义题库名称 | 预览页提供输入框，默认取文件名；重名允许（内部用唯一 id 区分） |
| A4 | 确认后写入本地库 | 全部成功或全部回滚（事务）；导入成功提示题数 |
| A5 | 题库列表 | 显示名称、题数、导入时间；按导入时间倒序 |
| A6 | 删除题库 | 二次确认；级联删除其题目、答题记录、会话；错题/收藏同步清理 |
| A7 | 编码兼容 | UTF-8（含 BOM）与 GBK/GB18030 自动识别；识别失败或乱码时给出明确错误而非静默导入乱码 |

### 7.2 CSV 规范（P0）

固定表头（顺序不敏感，列名大小写不敏感）：

```
id,content,type,option_a..option_e,correct_answer,explanation,category,chapter
```

- `type`：`single`（单选）/ `judge`（判断）；`multi`（多选）P1；`blank`（填空）P2
- `correct_answer`：单选/判断填 `A`–`E` 或 `对/错`（`true/false`、`T/F` 亦接受，导入时归一化为 `对`/`错`）；多选如 `A,C`
- 判断题选项固定为 对/错，可忽略 option_a/b
- 选项允许为空（判断题）；`explanation/category/chapter` 可为空
- `id` 建议连续，但只要求题库内不重复；缺失时按行号自动编号
- 容错：RFC 4180 引号转义、引号内换行/逗号必须正确解析；空行跳过；每行列数不足记为解析错误

### 7.3 刷题页（P0，核心页面）

**练习方式**（进入刷题前选择，P0 全做）：

| 方式 | 规则 |
|---|---|
| 顺序练习 | 按 `order_index` 升序 |
| 随机练习 | 以会话内持久化的随机种子打乱题序；恢复会话后题序不变 |
| 专项练习 | 先选章节/分类（取该题库 distinct 值，含题数），再进入；子集内再支持顺序/随机 |
| 错题重练 | 只刷错题本中未掌握的题（按最近做错时间倒序） |
| 收藏练习 | 只刷收藏的题（按收藏时间倒序） |

**背题模式（可随时切换）**：

- **模式 A · 浏览背题**：答案与解析默认展开；选项不可交互；无正误记录，但标记「已浏览」；支持收藏。
- **模式 B · 检验背题**：答案解析隐藏；点选项即时反馈——正确项绿色、错选项红色、其余置灰；随后解析展开；**选定后不可改**；选错自动入错题本，选对则累加「错题重练中做对次数」（仅错题重练会话）；支持收藏与笔记。

**模式切换状态保持**（P0，体验关键）：

| 切换 | 规则 |
|---|---|
| A → B | 题号不丢。若该题本会话内此前在模式 B 做过 → 恢复当时的选中与判定状态；否则重置为未选择、答案隐藏 |
| B → A | 保留已选状态，答案立即展开 |

> 产品决策：状态记忆范围限定为**当前会话**，跨会话不记忆历史选择（防止翻旧记录试答案，违背模式 B 检验初衷）。

**界面元素**：

- 顶栏：返回、题库名称、设置入口（当前会话的练习方式/模式快捷切换）
- 进度：`当前题号/总题数` + 可视化进度条
- 题目卡片：题型标签（单选/判断）、分类/章节 chip（可选展示）、题干、选项列表（支持长文本自动换行）
- 答案/解析区：动态显隐，展开带平滑动画
- 底部：上一题 / 下一题
- 答题卡：可折叠题号网格，状态四色（未做 / 已做对 / 已做错 / 已浏览 / 当前题）；点击跳转
- 收藏按钮：一键收藏/取消，状态即时反馈

**交互细节**（P0）：左右滑动手势切题；选项点击有水波纹与状态动画；答案展开过渡动画；答题卡点击快速跳转。

### 7.4 会话自动保存与恢复（P0）

**保存触发点**：① 每次切题立即保存；② 每 5 秒静默保存（状态无变化则跳过）；③ 进入后台 / 退出时兜底保存。

**恢复**：启动时检查活跃会话（含离开刷题页但未完成的会话）。未超过 **7 天**过期时间 → 弹窗显示：题库名、当前题号、已用时长、上次活跃时间；提供 **继续刷题 / 重新开始 / 下次不再询问**。超过 7 天自动标记过期并清理，不再提示。

- 「下次不再询问」：写入设置（仅静默启动弹窗），题库详情处仍保留「继续上次」手动入口，进度不丢。

### 7.5 错题本（P0）

- 集中展示全部**未掌握**错题（按题库分组或平铺 + 筛选，MVP 平铺 + 按题库筛选）
- 每题显示：累计做错次数、最后做错时间
- 在错题重练中累计答对 **2 次** → 自动标记「已掌握」移出列表（已掌握列表可在筛选中查看）
- 支持手动标记/取消「已掌握」
- 点击题目直接进入错题重练

### 7.6 收藏夹（P0）

- 独立于错题本；支持按题库筛选；可取消收藏
- 可直接开始收藏练习

### 7.7 笔记（P1）

模式 B 支持给题目添加/编辑自由文本笔记；题目卡片有笔记标识；刷题页与（未来的）笔记列表可见。数据模型中预留（见开发文档 `note` 表）。

### 7.8 设置（P0）

| 设置项 | 说明 |
|---|---|
| 清除所有数据 | 二次确认对话框（明确告知影响范围：题库+进度+错题+收藏全部删除） |
| 夜间模式 | 三态：跟随系统 / 浅色 / 深色 |
| 字体大小 | 小 / 标准 / 大 / 特大（叠加在系统 fontScale 之上） |
| 关于 | MIT License 全文、GitHub 仓库链接、版本号 |

## 8. 非功能需求

| 维度 | 要求 |
|---|---|
| 隐私 | **零网络权限**；所有数据仅存应用私有目录；卸载即清除 |
| 可靠性 | 切题保存失败不阻塞刷题（重试+下次保存覆盖）；强杀进程最多丢失当前题的未保存作答（实际为切题即存，损失≈0） |
| 性能 | 千题级题库导入 < 5s（带进度）；刷题页切题 < 100ms 无卡顿；所有 DB IO 不在主线程 |
| 兼容 | **minSdk 26（Android 8.0+，2026-08-30 决策，骨架原值 34）**，覆盖绝大多数学生旧机型；target/compile 36 |
| 体积 | 不引入图片/网络/大体积库，APK 目标 < 10MB |

## 9. MVP 路线与验收

| 阶段 | 内容 | 完成定义（DoD） |
|---|---|---|
| Phase 1 骨架 | 主题、Room 库、导航框架、首页空状态 | 冷启动进入空首页，能看到引导导入的空状态页 |
| Phase 2 刷题闭环 | CSV 导入+预览、题库列表、刷题页布局、模式 A/B、答题卡 | 用示例 CSV 完整走通：导入→刷题→判分→切模式不丢状态 |
| Phase 3 状态闭环 | 自动保存三触发点、恢复弹窗、错题归集+错题本、收藏 | 杀进程重开能续刷；连错 2 次进错题本；错题重练答对 2 次自动掌握 |
| Phase 4 打磨 | 深色模式、字体调节、空态/错误提示、设置页 | 四 Tab 完整可用，达到可发布状态（v1.0） |

## 10. 明确不做（Non-goals）

社交/排行/分享/社区；账号与云同步；广告与任何商业化；AI 答疑；拍照录题；真题考试倒计时；间隔重复算法（v1 不做，见远期）；内置题库内容（Reps 是空工具，题库永远是用户自备的）。

## 12. 远期方向（Post-MVP）

1. **间隔重复**：借 AnkiDroid/SM-2 思路，对错题安排复习计划
2. **PDF/Word 导入**：内置解析或配套开源转换脚本
3. **统计页**：正确率趋势、章节薄弱点、刷题时长
4. **导出**：错题本导出 CSV / 备份恢复（仍全离线，走系统分享面板）
5. **多端**：桌面端（Compose Multiplayer 天然潜力）
